# the-sacred-timeline
The sacred timeline is a semantic library and research workspace for ingesting document collections, extracting text, math, citations, and structure, then projecting them into timeline, graph, atlas, and lab views. It links science-history curation with indexing, OCR workflows and operator review tools.
